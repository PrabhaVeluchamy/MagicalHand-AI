# ✋ MagicHandAI

MagicHandAI is a Python-based interactive computer-vision project that explores hand tracking, gesture recognition, visual effects, and interactive gameplay.

The project combines hand-tracking technology with animated effects to create an engaging visual interaction experience.

## ✨ Features

* Hand-tracking interaction
* Gesture recognition
* Interactive visual effects
* Particle animations
* Spell and effect management
* Portal-based visual elements
* Heads-up display (HUD)
* Modular Python architecture
* Renderer and gameplay components

## 🛠️ Technologies Used

* Python
* OpenCV
* MediaPipe
* Computer Vision
* Gesture Recognition
* Particle Animation
* Interactive Graphics

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/PrabhaVeluchamy/MagicalHand-AI.git
```

### 2. Open the project directory

```bash
cd MagicalHand-AI
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

```bash
python main.py
```

## 🧪 Run Tests

```bash
python test.py
```

If the renderer tests are independent, you can also run:

```bash
python test_renderer.py
```
